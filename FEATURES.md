# SkillSwap — Features

## Student Features

- Profile creation with skills, bio, portfolio, social links
- AI-powered recommendations (6-factor compatibility scoring)
- Discover students with advanced filters
- Send/accept/reject mentorship & peer learning requests
- Real-time chat (Socket.IO) gated by active connections
- Session scheduling, confirmation, completion
- Calendar view of sessions
- AI learning roadmaps
- Endorsement system
- Badges & certificates
- Leaderboard (points & trust)
- Notifications (in-app + real-time)
- Account settings & privacy controls

## Mentor Features

- List skills they can teach
- Accept mentorship requests
- Schedule and conduct sessions
- Earn ratings and reviews
- Build teaching reputation

## Peer Learning Features

- Mutual skill exchange (React ↔ Python)
- Two-way teaching relationship
- Shared session scheduling

## Admin Features

- Dashboard with 21 stat cards
- User management (search, filter, suspend, delete)
- Institution management with merge
- Skill management with merge
- Session monitoring
- Badge & certificate CRUD
- Report moderation
- AI service monitoring
- System health dashboard
- Analytics (growth, sessions, skills, connections)

## AI Features

- Semantic skill matching (SBERT/TF-IDF)
- 6-factor compatibility scoring
- Learning roadmap generation
- Skill knowledge graph (NetworkX)
- Related skill suggestions
- Resume parsing & skill extraction
- Next-steps recommendations after sessions
- Graceful fallback when AI service is down
